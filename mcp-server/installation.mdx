## Connect from this page

Use the action button below to connect SolvaPay MCP with the correct endpoint.

<McpConnectActions />

OAuth-capable clients (Claude.ai, Claude Desktop) handle authentication automatically — just log in with your SolvaPay account. Config-based clients (Cursor, VS Code) need a secret API key from **SolvaPay Console > Developers > API Keys**, sent as `Authorization: Bearer <secret key>`.

| Property | Value |
|---|---|
| **Endpoint** | `https://mcp.solvapay.com/mcp` |
| **Transport** | Streamable HTTP (stateless) |
| **Auth header** | `Authorization: Bearer sk_sandbox_...` (or `sk_live_...` for production) |

The MCP server only reads the `Authorization` header. An `X-API-Key` header is ignored and the request fails with `Authentication required`.

## Cursor IDE

Add SolvaPay to `~/.cursor/mcp.json` (all projects) or `.cursor/mcp.json` in your project root:

```json ~/.cursor/mcp.json
{
  "mcpServers": {
    "solvapay": {
      "url": "https://mcp.solvapay.com/mcp",
      "headers": {
        "Authorization": "Bearer sk_sandbox_your_key_here"
      }
    }
  }
}
```

1. Replace `sk_sandbox_your_key_here` with your secret key.
2. Save the file. If `mcp.json` already has an `mcpServers` object, add the `solvapay` entry to it.
3. Open **Cursor Settings > MCP** and check that `solvapay` is enabled. Toggle it off and on if tools don't appear.

You can also use **Connect SolvaPay MCP > Install in Cursor** above, which writes the same entry.

After setup, SolvaPay tools are available in Cursor chat.

## VS Code

Add SolvaPay to `.vscode/mcp.json` in your workspace, or to your user `mcp.json` (**MCP: Open User Configuration**):

```json .vscode/mcp.json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "solvapay-secret-key",
      "description": "SolvaPay secret key (sk_sandbox_... or sk_live_...)",
      "password": true
    }
  ],
  "servers": {
    "solvapay": {
      "type": "http",
      "url": "https://mcp.solvapay.com/mcp",
      "headers": {
        "Authorization": "Bearer ${input:solvapay-secret-key}"
      }
    }
  }
}
```

1. Save the file.
2. Run **MCP: List Servers** and start the `solvapay` server.
3. Enter your secret key when VS Code prompts for it. VS Code stores it securely, so the key stays out of the file.

After setup, SolvaPay tools are available in Copilot Chat.

## Claude.ai (Web & Mobile)

SolvaPay can be added as a connector directly inside Claude.ai — no local configuration or API keys needed.

1. Go to **Settings > Connectors** in Claude.ai.
2. Click **Add** and enter the MCP server URL:
   ```
   https://mcp.solvapay.com/mcp
   ```
3. Click **Add custom connector**. Claude will redirect you to the SolvaPay login page.
4. Sign in with your SolvaPay provider account (email code, Google, or GitHub).
5. Review the permissions and click **Authorize**.
6. The connector is now active. Enable it in any conversation via the **+** button > **Connectors**.

OAuth is handled automatically — Claude securely stores the access token so you don't need to re-authorize each session. Only existing SolvaPay providers can connect; no new account is created during this flow.

## Claude Desktop

Add SolvaPay as a connector, the same way as in Claude.ai. Claude Desktop signs you in with OAuth, so you don't need an API key.

1. Open **Settings > Connectors**.
2. Click **Add custom connector** and enter `https://mcp.solvapay.com/mcp`.
3. Sign in with your SolvaPay provider account and click **Authorize**.

Don't add SolvaPay to `claude_desktop_config.json`. That file is for local servers that Claude Desktop starts itself, not for remote servers like `https://mcp.solvapay.com/mcp`.

## Claude API (Messages API)

When using Claude's Messages API with the MCP connector beta, pass your SolvaPay API key or a provider JWT as the `authorization_token`:

```json
{
  "mcp_servers": [
    {
      "type": "url",
      "url": "https://mcp.solvapay.com/mcp",
      "name": "solvapay",
      "authorization_token": "sk_sandbox_your_key_here"
    }
  ],
  "tools": [
    {
      "type": "mcp_toolset",
      "mcp_server_name": "solvapay"
    }
  ]
}
```

This requires the beta header `anthropic-beta: mcp-client-2025-11-20`. The API does not use the browser-based OAuth flow — pass the token directly.

## Other MCP Clients

The SolvaPay MCP Server uses **Streamable HTTP**. Any MCP client that supports this transport can connect.

Configure your client with:

| Property | Value |
|---|---|
| **Endpoint** | `https://mcp.solvapay.com/mcp` |
| **Transport** | Streamable HTTP (stateless) |
| **Authentication** | OAuth 2.0 (browser-based clients) or `Authorization: Bearer <secret key>` header (config-based clients) |

Most config-based clients accept a JSON entry in this shape:

```json
{
  "mcpServers": {
    "solvapay": {
      "url": "https://mcp.solvapay.com/mcp",
      "headers": {
        "Authorization": "Bearer sk_sandbox_your_key_here"
      }
    }
  }
}
```

## Using Multiple Environments

Create separate MCP server entries in your client:

- `solvapay-sandbox` with your sandbox API key
- `solvapay-production` with your production API key

Both use the same endpoint — the environment is determined by your API key prefix:

| Key Prefix | Environment | Data |
|---|---|---|
| `sk_sandbox_` | Sandbox | Test data only |
| `sk_live_` | Production | Real data |

## Verifying the Connection

After connecting, ask your AI assistant something simple like:

> "List my SolvaPay customers"

If the connection is working, you'll see a response from the `list_customers` tool. If your account is new, an empty list is expected.

## Troubleshooting

**"Authentication required" error**

For config-based clients (Cursor, VS Code): confirm your configuration sends `Authorization: Bearer <secret key>`. An `X-API-Key` header is ignored and gives this error. For OAuth clients (Claude.ai): try removing and re-adding the connector to re-authenticate.

**"Invalid or expired secret key" error**

The API key is being sent but is not valid. Verify it in **SolvaPay Console > Developers > API Keys**. Make sure you copied the full key.

**"Invalid or expired provider token" error**

Your OAuth session has expired. Remove the connector and re-add it — you'll be prompted to sign in again.

**Tools not appearing**

Re-open your AI assistant or reload MCP settings. Some clients require a full restart.
