---
title: "Add a paywall to an API or app"
description: "Use a SolvaPay SDK (TypeScript, Python, or Go) to add paywall checks to APIs, apps, and MCP tools with full customization."
---

Use this guide when you want full control and plan to integrate monetization directly in your codebase.

## Who this is for

- Teams building APIs, web apps, or custom MCP flows
- Teams that need custom auth, routing, or entitlement behavior
- Teams that want code-level control over monetization

## What you will achieve

By the end, your API or app enforces plan access with a SolvaPay SDK.

## Prerequisites

- A SolvaPay account
- A product and plan in the SolvaPay Console
- A TypeScript, Python, or Go project (an API, a web app's backend, or an MCP server)

## Steps

<Tabs>
  <Tab title="TypeScript">
    1. Run [CLI setup](/sdks/typescript/setup/cli) or [installation](/sdks/typescript/setup/installation).
    2. Complete [SDK quick start](/sdks/typescript/setup/quick-start).
    3. Choose the framework guide you need:
       - [Express](/sdks/typescript/guides/express)
       - [Next.js](/sdks/typescript/guides/nextjs)
       - [MCP](/sdks/typescript/guides/mcp)
    4. Configure auth using [custom auth](/sdks/typescript/guides/custom-auth) if needed.
    5. Add usage billing with [usage events](/sdks/typescript/guides/usage-events) where required.
  </Tab>
  <Tab title="Python">
    1. Follow [installation](/sdks/python/setup/installation).
    2. Complete the [quick start](/sdks/python/setup/quick-start): make a function paid and serve it from a route.
    3. For MCP tools, follow the [MCP guide](/sdks/python/guides/mcp).
    4. Record usage or read customers and purchases with the [API client](/sdks/python/guides/api-client).
  </Tab>
  <Tab title="Go">
    1. Follow [installation](/sdks/go/setup/installation).
    2. Complete the [quick start](/sdks/go/setup/quick-start): make a function paid and serve it from a `net/http` handler.
    3. For MCP tools, follow the [MCP guide](/sdks/go/guides/mcp).
    4. Record usage or read customers and purchases with the [API client](/sdks/go/guides/api-client).
  </Tab>
</Tabs>

## Verify

- Protected endpoints or tools return paywall responses for missing purchases
- Valid purchases pass and execute business logic
- Usage appears in sandbox data
