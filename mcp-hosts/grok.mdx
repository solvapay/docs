Grok shows text and links only. It does not render MCP UIs, so checkout and account pages open as SolvaPay-hosted pages in the system browser.

## What works

- Text and links: supported.
- MCP UIs: text and links only.
- Payment form: hosted page, in the system browser.
- Account pages: hosted page, in the system browser.

## Checkout

When a paid tool is blocked, the response text states the limit and includes a link to hosted checkout. The customer opens the link, pays, and returns to Grok. The next call to the paid tool runs.

## Account pages

Ask the assistant to manage the account. The `account` tool returns the current plan, usage and a link to the SolvaPay-hosted account page.

## MCP UIs

Grok ignores MCP UIs and uses only the markdown text of a response. Every SolvaPay response already contains a complete text answer with plain `https://` links, so nothing is lost.

## Connect your MCP server

1. Go to [grok.com/connectors](https://grok.com/connectors).
2. Select **New Connector**, then **Custom**.
3. Enter your MCP server URL and complete sign-in.

Business and Enterprise admins provision the connector in the xAI console first. See xAI's [connectors guide](https://docs.x.ai/grok/connectors).

## Known limitations

- There is no inline checkout. Card entry always happens on the hosted page.
- Your MCP server must be reachable over the public internet. Grok rejects `localhost` and private network URLs.
- Hosted checkout links expire after 15 minutes. Ask the assistant for a new link if one has expired.
