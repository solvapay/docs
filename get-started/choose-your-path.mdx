Use this page to choose your primary integration path before you build.

Every path uses the same secret API key and base URL. See [Authentication and base URL](/api-reference/authentication).

Each path has a step-by-step page from a new account to a first paid call:
[Managed MCP](/build/managed-mcp), [TypeScript SDK](/build/typescript-sdk), and
[agent skill](/build/agent-skill). The Python and Go SDKs start from their quick starts:
[Python](/sdks/python/setup/quick-start) and [Go](/sdks/go/setup/quick-start).

## Decide in 10 seconds

- Choose an **SDK** (TypeScript, Python, or Go) if you want to add monetization in your own code.
- Choose **Managed MCP** if you want SolvaPay to host auth, checkout, and paywall enforcement for your MCP server. No code required.

## Quick comparison

| Feature | SDK (TypeScript, Python, Go) | Managed MCP |
|---|---|---|
| Code changes required | Yes | None |
| Fastest setup | `npx solvapay@latest init` (TypeScript), `pip install solvapay`, `go get github.com/solvapay/solvapay-sdk/go` | Console setup |
| Authentication | Custom or OAuth | OAuth (Google or email code) |
| Supported platforms | Any API, MCP, or web app | MCP servers only |
| Hosting | Your infrastructure | Managed by SolvaPay |
| Customization | Full programmatic control | Configuration-based |

## Path A: SDK (recommended for developers)

Pick the SDK for your server's language. All three check the same plans, bill the
same way, and show the same paywall messages: a shared conformance suite checks
the Python and Go SDKs against the TypeScript one on every change.

<Tabs>
  <Tab title="TypeScript">
    Start with one command from your project root:

    ```bash
    npx solvapay@latest init
    ```

    It signs you in, writes your secret key to `.env`, and installs the SDK packages.

    - [CLI setup](/sdks/typescript/setup/cli)
    - [SDK quick start](/sdks/typescript/setup/quick-start)
    - [TypeScript SDK introduction](/sdks/typescript/intro)
  </Tab>
  <Tab title="Python">
    ```bash
    pip install solvapay
    ```

    Copy a sandbox secret key from Console > **Developers** > **API Keys** into `SOLVAPAY_SECRET_KEY`.

    - [Installation](/sdks/python/setup/installation)
    - [Quick start](/sdks/python/setup/quick-start)
    - [Python SDK introduction](/sdks/python/intro)
  </Tab>
  <Tab title="Go">
    ```bash
    go get github.com/solvapay/solvapay-sdk/go
    ```

    Copy a sandbox secret key from Console > **Developers** > **API Keys** into `SOLVAPAY_SECRET_KEY`.

    - [Installation](/sdks/go/setup/installation)
    - [Quick start](/sdks/go/setup/quick-start)
    - [Go SDK introduction](/sdks/go/intro)
  </Tab>
</Tabs>

## Path B: Managed MCP

Managed MCP is SolvaPay's managed auth and monetization path for MCP servers. You
keep ownership and hosting of your MCP server; SolvaPay sits in front of it as a reverse proxy and
handles OAuth, paywall enforcement, and billing.

### Choose this path if you:

- You want to launch quickly without code changes
- You are monetizing an MCP server
- You are comfortable with OAuth sign-in for end users

### Get started

- [Managed MCP overview](/no-code-mcp/overview)
- [Managed MCP quick start](/no-code-mcp/quick-start)

## Can I use both?

Yes. Some teams use Managed MCP for MCP server access while using the SDK for web apps or APIs.
Both share the same plans, customers, and billing in your SolvaPay account.

## Using an AI coding agent?

Start with one command for guided integration in any compatible AI coding tool:

```bash
npx skills add https://solvapay.com
```

With a `skills` CLI older than 1.5.7, use `npx skills add solvapay/skills` instead.
